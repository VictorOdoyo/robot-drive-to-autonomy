# References and conventions

These primary sources provide background and coordinate-frame context.
This repository implements its own small numerical models; it does not copy
the referenced software or claim compatibility with a ROS deployment.

- Frank Dellaert and Seth Hutchinson, *Introduction to Robotics and Perception*,
  [Differential-drive motion model](https://www.roboticsbook.org/S52_diffdrive_actions).
  Background for wheel-to-body kinematics and planar robot motion.
- Thomas Moore and Daniel Stouch,
  [A Generalized Extended Kalman Filter Implementation for the Robot Operating System](https://docs.ros.org/en/kinetic/api/robot_localization/html/_downloads/robot_localization_ias13_revised.pdf).
  Background for multisensor nonlinear state estimation.
- [robot_localization sensor-data preparation](https://github.com/cra-ros-pkg/robot_localization/blob/rolling-devel/doc/preparing_sensor_data.rst).
  Frame and measurement-preparation context. Robotlab uses a deliberately
  smaller four-state planar filter.
- [SciPy discrete algebraic Riccati equation documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.solve_discrete_are.html).
  Solver used in the sampled LQR study.
- [NumPy load documentation](https://numpy.org/doc/stable/reference/generated/numpy.load.html).
  Replay archives are loaded with pickle disabled.

Equations, state definitions, physical scope and modeling choices are recorded
in [physics.md](physics.md), [control.md](control.md), [estimation.md](estimation.md)
and [navigation.md](navigation.md). Tests favor independent conservation laws,
analytical limits and cross-method comparisons over reproducing implementation
formulas in assertions.

All reported data are generated by the repository's simulations. They are
not measurements from a real motor, battery, IMU, lidar or mobile robot.
